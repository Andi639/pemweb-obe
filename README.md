## Deskripsi Proyek
Proyek ini merupakan repositori awal untuk latihan dan tugas praktikum Pemrograman Web berbasis Outcome-Based Education (OBE).

## Teknologi
- HTML5
- PHP 8.4
- Laragon 5

## Cara Menjalankan Proyek
1. Jalankan aplikasi **Laragon 5**, lalu klik tombol **Start All**.
2. Pastikan versi PHP yang aktif adalah **PHP 8.4** (Laragon > PHP > Version).
3. Buka browser dan akses URL lokal berikut:
   `http://localhost/pemweb-obe/`
